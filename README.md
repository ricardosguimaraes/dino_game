# 🦖 DINO GAME

Um jogo do dinossauro inspirado no jogo offline do Chrome, desenvolvido com HTML, CSS e JavaScript puro.

## 🎮 Como Jogar

### Controles:

- **Espaço** - Pular
- **Seta para cima** - Pular
- **W** - Pular
- **Clique do mouse** - Pular
- **Toque na tela** - Pular (dispositivos móveis)

### Objetivo:

Desvie dos cactos pulando e tente conseguir a maior pontuação possível!

## ✨ Funcionalidades

- ✅ **Sistema de pulo funcional** - Animações suaves
- ✅ **Sistema de pontuação** - Pontuação em tempo real
- ✅ **Dificuldade progressiva** - Velocidade aumenta com a pontuação
- ✅ **Detecção de colisão** - Sistema preciso de colisão
- ✅ **Tela de game over** - Interface moderna com botão de restart
- ✅ **Responsivo** - Funciona em desktop e mobile
- ✅ **Múltiplos controles** - Teclado, mouse e toque

## 🚀 Como Executar

1. Clone ou baixe os arquivos
2. Abra o arquivo `index.html` no navegador
3. Comece a jogar!

## 📁 Estrutura do Projeto

```
dino_game/
├── index.html          # Estrutura HTML do jogo
├── style.css           # Estilos e animações
├── script.js           # Lógica do jogo (classe DinoGame)
├── dino.png           # Sprite do dinossauro

```

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilos, animações e responsividade
- **JavaScript ES6+** - Lógica do jogo orientada a objetos
- **Canvas API** - Para detecção de colisão precisa

## 🎯 Características Técnicas

### Sistema de Jogo:

- **Classe DinoGame**: Arquitetura orientada a objetos
- **Animações CSS**: Pulo suave com keyframes
- **Detecção de colisão**: Usando getBoundingClientRect()
- **Sistema de pontuação**: Incremento automático
- **Velocidade dinâmica**: Aumenta com a pontuação

### Interface:

- **Design moderno**: Gradientes e sombras
- **Responsividade**: Adaptação para mobile
- **Feedback visual**: Efeitos de shake no game over
- **Acessibilidade**: Múltiplos controles
